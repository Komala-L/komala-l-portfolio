# Komala L — Developer Portfolio

A modern, responsive developer portfolio built with React, TypeScript, and Tailwind CSS. The portfolio combines a clean glassmorphism interface with an interactive Aurora background system, subtle animations, and responsive layouts across desktop, tablet, and mobile devices.

## ✨ Features

- Responsive portfolio layout
- Interactive Aurora background
- Animated Hero section
- Responsive navigation with active-section tracking
- Profile image with glassmorphism effects
- Social links and contact actions
- Open to Work indicator
- Framer Motion animations
- Responsive desktop, tablet, and mobile layouts
- Accessibility-aware motion handling
- Performance-conscious background animations

## 🛠️ Tech Stack

- React
- TypeScript
- Tailwind CSS
- Vite
- Framer Motion
- Lucide React
- HTML5 Canvas
- Git & GitHub
